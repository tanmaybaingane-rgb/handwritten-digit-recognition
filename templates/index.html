Dataset Overview: Optical Recognition of Handwritten Digits

The project utilizes scikit-learn's built-in load_digits dataset, containing normalized 8×8 grayscale bitmap images extracted from pre-printed form digits.

Algorithm Insights & Findings

Top Performers: SVM (99.17%) and KNN (98.61%)

Support Vector Machines with an RBF kernel and K-Nearest Neighbors excel at handwritten digit recognition because digit classes occupy non-linear, curved decision manifolds in pixel space.

Ensemble vs Single Tree: Random Forest (96.39%) vs Decision Tree (82.50%)

An individual decision tree suffers from high variance and overfits to specific pixel cutoffs. Averaging 200 trees in Random Forest reduces variance dramatically, boosting accuracy by over 13%.

Naive Bayes Limitation (81.11%)

Gaussian Naive Bayes makes a strong independence assumption between pixel features. In handwritten digits, adjacent pixels are intensely correlated, violating the assumption.

Innovation 1: PCA Dimensionality Reduction

Principal Component Analysis (PCA) projects the 64 pixel features onto orthogonal principal axes of maximum variance. We evaluated an SVM (RBF) pipeline across 5, 10, 15, 20, 30, 40, and 64 components.

Components vs. Test Accuracy

Accuracy plateaus at 98.89% with only 15 components, matching the performance of all 64 original features.

Key Finding: 76.6% Dimension Reduction

Just 15 principal components retain sufficient structural variance to classify digits at 98.89% accuracy. This enables significant memory and computational savings for embedded or resource-constrained deployments.

Innovation 2: Robustness to Image Noise

Real-world digit scanning introduces blur, grain, and sensor noise. We evaluated the resilience of all six models trained on clean data when subjected to Gaussian noise levels of standard deviation σ ∈ {0, 1, 2, 3, 4}, clipped to [0, 16].

Crucial Engineering Findings

SVM & KNN Maintain High Robustness

SVM and KNN maintain over 95% test accuracy even at noise level 4. Their continuous distance and margin calculations naturally smooth out zero-mean Gaussian fluctuations.

Why Naive Bayes Collapses to ~12%

Border pixels in clean training images are almost always 0. Naive Bayes estimates an extremely tight variance for these pixels. When random noise perturbs border pixels to non-zero, their likelihood under Gaussian NB drops near zero, causing catastrophic misclassification.

The Feature Scaling Discovery

Applying StandardScaler to border pixels magnifies near-zero variance features, destroying noise robustness. Keeping the native [0, 16] scale preserved high noise immunity.

Problem Statement & Objectives

Problem Statement

Given an 8×8 grayscale image of a handwritten digit, predict which digit from 0 to 9 it represents. The system must be rigorously benchmarked using multiple algorithms, validated across 5-fold cross-validation, tested for feature dimensionality reduction via PCA, and examined under sensor noise.

Key Objectives

  • Compare 6 classical ML models on an identical train/test split.
  • Compute macro-averaged precision, recall, F1, test accuracy, and 5-fold CV score.
  • Assess PCA dimensionality reduction across 7 component thresholds.
  • Conduct empirical noise stress testing across 5 noise levels.
  • Analyze failure cases via confusion matrix and misclassified image inspection.

Methodology, Limitations & Scope

Methodology

Using scikit-learn's load_digits, an 80/20 stratified split is established with random_state=42. No feature standardization is applied, which proves vital for noise robustness. All models are trained deterministically and evaluated against macro-averaged metrics.

Limitations & Future Scope

  • Resolution: The digits dataset consists of small 8×8 low-resolution bitmaps; future iterations can scale to MNIST (28×28).
  • Hyperparameter Tuning: Baseline parameters were utilized; GridSearchCV can optimize kernels and tree depths.
  • Deep Learning: Traditional ML algorithms were used here; future work can explore Convolutional Neural Networks (CNNs).
